# Drax Learnable Weighted Feature Fusion Notes

## Overview

Drax currently combines residual updates from a ConvNeXt-style local branch and a self-attention global branch using a fixed average:

```text
conv_delta = ConvNeXtBlock(x) - x
attention_delta = SelfAttention2D(x) - x
fusion = 0.5 * (conv_delta + attention_delta)
output = x + fusion
```

In efficient attention mode, the attention residual is computed in a reduced channel space and projected back to the original dimension:

```text
reduced = attn_down(x)
attention_delta = attn_up(SelfAttention2D(reduced) - reduced)
```

The proposed modification replaces equal averaging with learnable weighting:

```text
fusion = w_conv * conv_delta + w_attention * attention_delta
output = x + fusion
```

The weighting operation itself is not new. Its closest precedent depends on how the weights are produced:

- global trainable scalar weights are closest to BiFPN
- input-dependent channel-wise weights are closest to Selective Kernel Networks
- input-dependent spatial-channel weights are closest to Attentional Feature Fusion

The Drax-specific aspect is the application of weighted fusion to extracted residual deltas from heterogeneous local-convolution and global-attention branches.

## BiFPN-Style Fusion

EfficientDet's BiFPN recognizes that incoming features can contribute unequally. Its fast normalized fusion uses nonnegative trainable scalar weights:

```text
output = sum(ReLU(w_i) * input_i) / (epsilon + sum(ReLU(w_i)))
```

For Drax, this becomes:

```text
a_conv = ReLU(theta_conv)
a_attention = ReLU(theta_attention)

fusion = (
    a_conv * conv_delta
    + a_attention * attention_delta
) / (epsilon + a_conv + a_attention)

output = x + fusion
```

This is essentially BiFPN-style weighted fusion applied to two branch residuals rather than to features from different pyramid levels.

An alternative is softmax normalization:

```text
w_conv, w_attention = softmax([theta_conv, theta_attention])
fusion = w_conv * conv_delta + w_attention * attention_delta
```

Initializing both logits to zero produces:

```text
w_conv = 0.5
w_attention = 0.5
```

This exactly reproduces the current fixed-average fusion at initialization. It also prevents negative weights and keeps the fusion as a convex combination.

Properties:

- only two additional trainable parameters per Drax block
- weights are shared across all inputs, channels, and spatial positions
- weights reveal the average learned preference of the block
- weights cannot adapt to individual images or image regions

## SKNet-Style Fusion

Selective Kernel Networks contain parallel convolution branches with different receptive fields. SKNet follows a `Split-Fuse-Select` procedure:

```text
branch1 = Conv3x3(x)
branch2 = Conv5x5(x)
summary = GlobalAveragePool(branch1 + branch2)
weights = softmax(MLP(summary))
output = weights[0] * branch1 + weights[1] * branch2
```

The selection weights depend on the current input and are normally produced per channel. For two branches and channel `c`:

```text
a_c + b_c = 1
output_c = a_c * branch1_c + b_c * branch2_c
```

A corresponding Drax implementation would be:

```text
summary = GlobalAveragePool(conv_delta + attention_delta)
weights = softmax(MLP(summary))

fusion = (
    weights.conv * conv_delta
    + weights.attention * attention_delta
)

output = x + fusion
```

Here, `weights.conv` and `weights.attention` have one value per channel. Different images and channels can therefore prefer different residual branches.

Properties:

- input-dependent rather than globally fixed after training
- channel-wise local-versus-global branch selection
- substantially cheaper than full spatial attention
- directly aligned with the question of when convolution or attention should be trusted
- adds a gating network, so improvements must be evaluated against a parameter-matched baseline

## AFF-Style Fusion

Attentional Feature Fusion takes two feature tensors, initially integrates them, and generates a complementary attention mask from local and global channel context:

```text
initial = X + Y
mask = sigmoid(LocalContext(initial) + GlobalContext(initial))
output = mask * X + (1 - mask) * Y
```

The complementary weights ensure that the two branch weights sum to one at each gated feature position.

Applied to Drax:

```text
initial = conv_delta + attention_delta
mask = sigmoid(LocalContext(initial) + GlobalContext(initial))

fusion = (
    mask * conv_delta
    + (1 - mask) * attention_delta
)

output = x + fusion
```

The global context path summarizes the full feature map, while the local context path preserves spatial information. The resulting mask can select convolutional corrections in some channels or locations and attention corrections in others.

Properties:

- input-, channel-, and spatially dependent fusion
- more expressive than scalar or SKNet-style channel weighting
- able to model spatial variation in the usefulness of local and global context
- higher parameter and computation cost
- harder to attribute improvements solely to fusion because the gating network adds representational capacity

## Comparison

| Method | Weight granularity | Input-dependent | Normalization | Relative cost | Closest Drax interpretation |
| --- | --- | --- | --- | --- | --- |
| Fixed average | One fixed pair | No | `0.5 + 0.5 = 1` | None | Current baseline |
| BiFPN-style | One trainable scalar per branch | No | ReLU normalization or softmax | Negligible | Globally learned local/global balance |
| SKNet-style | Per branch and channel | Yes | Softmax across branches | Low | Image- and channel-dependent local/global selection |
| AFF-style | Per channel and spatial location | Yes | Complementary sigmoid mask | Moderate | Spatial-channel local/global selection |
| ASFF-style | Per branch and spatial location | Yes | Softmax across branches | Moderate | Spatially varying branch selection shared across channels |

The methods answer progressively more expressive questions:

```text
BiFPN-style: Which branch is generally more useful?
SKNet-style: Which branch is useful for this image and channel?
AFF-style: Which branch is useful at this image location and channel?
```

## Gaps and Risks

### Branch magnitude imbalance

The current two residual branches are not necessarily scale-calibrated:

- `ConvNeXtBlock` applies a channel-wise layer scale initialized to `1e-6`
- `SelfAttention2D` does not apply an equivalent small residual scale
- the projected attention delta may therefore be much larger than the ConvNeXt delta early in training

Learned weights can compensate for magnitude differences, but this makes them difficult to interpret. A small attention weight would not necessarily mean that attention is less useful; it may only mean that its delta has a larger norm.

Possible controls:

- give both residual branches comparable learnable layer scales
- normalize branch deltas before fusion
- report the norm of each raw and weighted delta during evaluation
- compare fusion weights only after accounting for branch magnitude

### Unconstrained weights

Using direct parameters without normalization:

```text
fusion = w1 * f1 + w2 * f2
```

allows negative or arbitrarily large coefficients. This changes both branch selection and the overall residual magnitude. It can also make optimization unstable or interpretation ambiguous.

Softmax or BiFPN-style normalization is preferable for the initial study because it separates relative branch preference from residual amplification.

### Added-capacity confounding

SKNet- and AFF-style methods introduce additional networks to predict fusion weights. Any accuracy improvement could result from:

- better branch selection
- increased parameter count
- additional nonlinear transformations
- regularization effects from the gating mechanism

Adaptive variants should therefore be compared with parameter-matched controls where practical.

### Branch collapse

The learned fusion may consistently select only one branch. This could indicate:

- one branch is unnecessary
- the branch scales are poorly calibrated
- the gate saturated too early
- the training objective does not reward complementary behavior

Useful diagnostics include branch-weight distributions, delta norms, gradient norms, and cosine similarity between branch deltas.

## Recommended Experiment Sequence

Start with the smallest change that directly tests whether equal weighting is suboptimal:

```text
1. conv_delta only
2. attention_delta only
3. fixed 0.5 / 0.5 fusion
4. softmax-normalized learned scalar fusion
5. SKNet-style channel-wise adaptive fusion
6. AFF-style spatial-channel adaptive fusion
```

The primary proposed modification should be softmax-normalized learned scalar fusion:

```text
theta = learnable_parameter([0.0, 0.0])
w_conv, w_attention = softmax(theta)

fusion = w_conv * conv_delta + w_attention * attention_delta
output = x + drop_path(fusion)
```

Reasons:

- it begins exactly at the existing fixed average
- it adds only two parameters per block
- it provides the cleanest comparison with the current implementation
- it is easy to describe as BiFPN-inspired normalized weighted fusion
- it establishes whether more expressive adaptive gating is justified

For every experiment, report:

```text
classification accuracy and loss
parameter count and FLOPs
training and inference time
learned branch-weight values or distributions
mean norm of each raw branch delta
mean norm of each weighted branch contribution
cosine similarity between conv_delta and attention_delta
```

## Research Positioning

The proposed learned scalar fusion should not be described as a new feature-fusion operation. It is best positioned as:

```text
BiFPN-inspired normalized learnable weighting applied to local-convolution and global-attention residual deltas.
```

If input-dependent channel weights are used, the positioning becomes:

```text
SKNet-inspired adaptive channel-wise selection between local and global residual updates.
```

If spatial-channel masks are used, the positioning becomes:

```text
AFF-inspired spatial-channel selection between local and global residual updates.
```

A concise Drax-specific research framing is:

```text
Residual-delta extraction with learned branch selection between heterogeneous local convolutional and global self-attention updates.
```

The potentially distinctive research question is not whether weighted feature fusion works in general. It is whether explicitly weighting residual deltas from heterogeneous local and global operators improves their complementarity, calibration, and efficiency compared with fixed averaging.
